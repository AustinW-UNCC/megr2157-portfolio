# A8 – Gears

Objective - 

For this assignment, I was tasked with making a gearbox for 2 predetermined gears based on my knowledge of fits and journal bearings. I had to calculate stress and torques and decide which bearing material and sizes to use in order to allow the gears to rotate properly and be able to handle the loads required for this assembly.
