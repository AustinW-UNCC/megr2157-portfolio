# A4 – [Motor Mount]

For this assignment I was asked to design and create a motor mount for a brushed 24v DC Gear Motor. I liked this challenge a lot because it's the first time we have combined all steps of the design process so far and made an entire part based on a pre-existing piece. This felt like a very real-life type of scenario and it made the project feel like I was actually preparing to go into the workforce where a problem like this would need to be solved.
