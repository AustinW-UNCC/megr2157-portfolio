Part 5 - Lessons Learned - 

Throughout this assignment I learned how engineers decide which types of belts to use when designing a pulley system. I always just assumed that the belt types and length were based on how far apart the pulleys are. However, based on the amount of tension required for the belt. this number changes drastically. I also leaned into the fact that even though the minimum diameter that the shaft required was 0.13 inches, engineers would rather choose a larger, but more common size to work on the system with. This is due to lowering costs by using more common parts and allows them to save money by using more common fitting types in systems where shafts and pipes must be attached to one another.
